USB Block Group Policy (GPO)

Created this GPO to protect the organization from security risks related to USB devices. USB storage is one of the most common ways malware enters a network, and it also creates a significant risk of data loss and theft.

Steps

1. Why I Used the Computer Configuration Path

I used the Computer Configuration path because blocking USB storage must apply to the machine itself—regardless of which user logs in. This ensures consistent enforcement of the security rule across all accounts and prevents users from bypassing the restriction by switching profiles.

2. Enabling the USB Block Settings

Enabling these settings prevents Windows from reading or writing to USB storage devices, effectively blocking flash drives, external hard drives, and similar media.

3. Verifying the Policy Was Applied

I manually triggered a Group Policy refresh on the client system using gpupdate /force and verified that the USB-block security policy was successfully applied.
