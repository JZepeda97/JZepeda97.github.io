USB Block Group Policy (GPO)

This project shows how I created a Group Policy Object (GPO) to block USB storage devices on domain-joined systems. USB storage is one of the most common ways malware enters a network and also poses a significant risk of data loss and theft.

Why This Matters

USB devices are a major entry point for malware and a common method for unauthorized data transfer. Blocking USB storage helps protect sensitive data and reduces attack vectors in a Windows domain environment.

GPO Configuration Steps

1. Why I Used the Computer Configuration Path

I used the Computer Configuration path because blocking USB storage must apply to the machine itself—regardless of which user logs in. This ensures consistent enforcement across all accounts and stops users from bypassing the restriction by switching profiles.

2. Enabling the USB Block Settings

In Group Policy Management, I enabled the following settings to block USB storage device access:

  • Removable Disks: Deny read access
  • Removable Disks: Deny write access
  • Removable Disks: Deny execute access

These settings prevent Windows from reading or writing to USB storage devices, effectively blocking flash drives, external hard drives, and other removable media.

3. Verifying the Policy Was Applied

On the client system, I manually triggered a policy refresh using: 

gpupdate /force

I then verified the GPO was active by testing USB access and checking applied GPOs using: 

gpresult /r

Summary

This GPO helps protect the domain environment by blocking unauthorized USB storage usage. It reduces the chances of malware infections and prevents users from copying sensitive data to external devices.
