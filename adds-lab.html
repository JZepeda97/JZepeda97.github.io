Active Directory Domain Services (AD DS) Lab

This project demonstrates how I installed and configured Active Directory Domain Services (AD DS) on a Windows Server 2019 VM. The goal was to create the jzdomain.local domain, configure DNS, and promote the server to a Domain Controller.
